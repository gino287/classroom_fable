# 設計方向（任務 3.2）

寫於 2026-11-11。三個方向，最後選「C 混合」。調查依據見 `research_ui.md`，成品截圖見 `screenshots/`。

## 方向 A：教室沙盒

```
┌──────────────────────────────────────────────┐
│  [講台]              投影片 8：Logic used in AI │
│   🙂  😕  🙂  🙂     ┌───────────────────┐    │
│   🙂  😵  🙂  😕     │ s06：完全跟不上…  │    │
│   🙂  🙂  😕  🙂     └───────────────────┘    │
│   ▶ ━━━━━━●━━━━━━━━━━━━━━  8 / 22            │
└──────────────────────────────────────────────┘
```

- **長什麼樣**：一間俯視的教室，學生是小人，頭上有表情和對話泡泡，按播放一張一張上課（Generative Agents、AgentSchool 那一類）。
- **最適合傳達**：「這是一群 AI 學生在上課」的感覺。
- **優點**：最有趣，觀眾馬上懂在看什麼。
- **缺點**：回答不了「模擬跟真實像不像」；畫面上全是 AI 的說法（狀態、想法），沒有一樣可以驗證，不誠實的風險最高。
- **成本**：中到高（要畫角色、動畫）。

## 方向 B：分析儀表板

```
┌───────────────────────┬──────────────────────┐
│ 每題答對率             │ 最難的 3 題           │
│ Q1  ──●────◆──        │ 1. Q7  真實 13%       │
│ Q2  ─────────◆●       │ 2. Q3  真實 44%       │
│ Q3  ──◆────────●      │ 3. Q1  真實 56%       │
├───────────────────────┴──────────────────────┤
│ 投影片   1  2  3  4  5  6  7  8  9 …          │
│ 模擬卡點 ░  █  ▓  ▓  ░  ░  ▒  ▒  ░            │
│ 真實答錯    █     ░           ▓  ▒            │
└──────────────────────────────────────────────┘
```

- **長什麼樣**：像 Kahoot 的課後報告：每題模擬 vs 真實並排、難題清單、投影片熱圖。
- **最適合傳達**：「卡在哪」「準不準」，全部是可驗證的數字。
- **優點**：一目了然、誠實、做起來最快。
- **缺點**：不有趣；看不到「上課」的過程，觀眾不會感覺到這是模擬出來的學生。
- **成本**：低。

## 方向 C：混合——上面一句結論，下面三個分頁（選這個）

```
┌──────────────────────────────────────────────────────────┐
│ 模擬教室  [小學|高中] 第①②③…⑫堂          [MOCK] [簡報模式] │
├──────────────────────────────────────────────────────────┤
│ 模擬：最多人沒聽懂 投影片 2   │ 像不像 │ 平均差 │ 最難 3 題 │
│ 真實：答錯最多     投影片 2 ✓ │ 像 .81 │ 11 點  │  1 / 3   │
├──────────────────────────────────────────────────────────┤
│ [① 上課回放] [② 課後測：模擬 vs 真實] [③ 卡點熱圖]        │
│  ①＝方向 A 的教室（座位＋狀態符號＋想法泡泡＋時間軸）      │
│  ②＝方向 B 的每題並排＋難題清單                           │
│  ③＝方向 B 的投影片熱圖＋學生×投影片矩陣                  │
└──────────────────────────────────────────────────────────┘
   點任何學生 → 右側滑出他的設定、每張狀態、每題答案和理由
```

- **長什麼樣**：最上面永遠有一列結論（全班卡在哪、像不像）。下面三個分頁，第一頁是 A 的教室回放，第二、三頁是 B 的數字對照。點任何一位學生會從右邊滑出他的資料。
- **最適合傳達**：先用結論列回答 10 秒問題，再用回放讓人有感，最後用對照圖證明。
- **優點**：四個選擇標準都顧到（見下表）。簡報模式剛好照「上課 → 模擬說卡在哪 → 真實呢 → 像不像」的順序走。
- **缺點**：三個分頁，要切換；每一頁都比單做 A 或 B 簡單一點。
- **成本**：中。教室用圓形符號代替角色圖，省掉畫圖的成本。

## 用四個標準比較

| 標準（依重要性） | A 沙盒 | B 儀表板 | C 混合 |
| --- | --- | --- | --- |
| 1. 一目了然（10 秒看懂卡在哪、像不像） | 差：沒有對照 | 好 | 好：結論列永遠在最上面 |
| 2. 誠實（可驗證 vs AI 說法分得出來） | 差：全是 AI 說法 | 好：全是數字 | 好：兩種都有，用實心／虛線和標籤分開 |
| 3. 有趣、適合展示 | 好 | 差 | 好：有回放、有簡報模式 |
| 4. 能接真資料、能延伸 | 普通 | 好 | 好：第 2 步已經有示意；教師 agent 面板可以放在右側抽屜的位置 |

## 選擇：C，理由

1. 第一優先是「一目了然」，A 做不到；第三優先是「有趣」，B 做不到。C 是唯一不犧牲前三項的。
2. 「誠實」在 C 裡變成畫面的規則，而不是只能二選一：
   - **實心標記＋「可驗證」標籤**：作答對錯、答對率（可以跟真實資料比）。
   - **虛線框＋「AI 說法・無法驗證」標籤**：想法、理由、懂／困惑／卡住的狀態。
   - **MOCK 斜紋標籤**：只要資料來源是假的，頂部、每個相關區塊、學生面板都會出現。
3. 之後接上真的模擬，只要把檔案放進 `data/sim/` 並在 `index.json` 加一行，畫面不用改（見 `data_format.md`）。

## 沒做進去的想法

- 像素角色、走動動畫：成本高，而且會讓 AI 學生看起來比實際更「像人」，跟誠實原則衝突。
- 知識圖譜（AgentSchool 的做法）：我們的模擬沒有輸出這個東西。
- 散佈圖（x＝真實、y＝模擬）：統計上最標準，但一般觀眾要解釋才看得懂；每題一列的並排圖可以直接指著某一題講。相關係數 r 放在結論列。
