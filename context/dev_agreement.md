# 開發共識與假設清單（2026-11-09 版，副本，只供參考）

## 程式碼共識
- Gino 有程式基礎、正往中階發展：懂變數、條件、迴圈、函式、遞迴、基本資料結構；對特殊語法、進階技巧、部分函式庫 API 不熟。不要當新手，也不要過度工程化。
- 精簡與易讀並重；常見實用語法和函式庫可以用；避免沒必要的抽象。命名簡短有意義。
- 看得懂的不註解；複雜或不直覺的地方加簡短中文註解；值得學的進階寫法簡短說明用途。
- 每個檔案開頭寫「出處表」；給足上下文，讓 Gino 能把任何一段複製給別的 AI 自己問懂。
